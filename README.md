\# AI-Powered Real-Time Credit Card Fraud Detection



An AI-powered credit card fraud detection system using Machine Learning, Random Forest, Risk Scoring and SHAP Explainable AI.



\## Project Overview



This project detects fraudulent credit card transactions using a Random Forest Classifier. It also generates a risk score from 0 to 100 and provides SHAP-based explanations for model predictions.



\## Dataset



The project uses a credit card transaction dataset containing 284,807 transactions and 31 features.



The dataset is not included in this repository because of its large file size.
